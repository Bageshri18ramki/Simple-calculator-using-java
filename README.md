# Java Calculator

A simple calculator program written in Java using loops and conditional statements.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Handles invalid operators
- Prevents division by zero
- Exit option using x or X

## Concepts Used
- Scanner class
- while loop
- if-else statements
- Operators
- User input handling

## How to Run

1. Compile the program

```bash
javac Calculator.java
```

2. Run the program

```bash
java Calculator
```

## Example

```text
Enter the operator: +

Enter 2 numbers: 5 7
```
